# 图名、图号原属性保留试用版（2026-10-14）

本版解决固定模板字号适配不适用于不同图签的问题。以此前失败原因及详情按钮版本为基础。

## 处理规则

- 对原本地图签中的图名、图号，读取每个 ATTRIB 实例的完整文字属性体。坐标、字高等已包含原图签的实例变换，不再按新模板重复缩放。
- 将文字属性体用于新图签，保留源字高、宽度系数、字体样式、插入点、对齐点、旋转、倾斜、方向及嵌入 MTEXT 的宽度、字高、定位和格式。新属性的实体标识、所属图签及扩展字典仍使用新实体，避免悬挂引用。
- 原文字内容未编辑时，原始文字与格式原样保留，包括换行和内嵌格式命令。用户显式编辑内容时，保留文字几何和起始格式；混合字体、逐段富文本的编辑仍需单独检查。
- 读取原图属性成功后，跳过图名、图号的模板字号适配及长图号压缩。不按 DWG 文件名、案例编号或固定比例做特殊分支。
- 无法取得原文字属性体（例如仅有外参代理文字、散文字重建）时，不以模板参数冒充原属性；报 CFR-E109 并停止本文件处理。源 DWG 不被覆盖。这类输入仍需要后续补充原文字几何提取支持。
- 本次没有放宽图框/图签变换的最终验收规则；微小块缩放差异仍可能被严格验收判红，应按详情区分。

## 验证范围

1. 使用用户提供的 5 组原/处理后诊断数据，匹配 76 个图名、图号属性。对生产 AutoLISP 的属性捕获、数据重建及写入逻辑执行数据回放（CAD 数据库操作由测试替身提供）。
2. 所有 76 个属性在原内容不变时，文字属性体保持一致，新实体标识与所有者保留；没有调用模板适配或图号压缩。显式改字的测试保留非文字几何字段。
3. AutoLISP 结构检查及软件编译通过；统一信息和人员清空的既有检查通过。
4. 尚未在当前执行环境完成原生 AutoCAD 的保存、重开及屏幕/打印验证。数据回放通过不等于全部 DWG 实测通过。必须用原图重新处理并导出新报告核对。

## 使用

下载独立试用包，解压到新文件夹，运行 CAD-100/CAD-100.exe。先测试原来的 01–05 原图；不要将旧输出当作本轮原图。

附带 CAD100_TITLE_GEOMETRY_AUDIT.lsp，只读诊断命令 CAD100TITLEAUDIT。分别在原图及新输出中 APPLOAD 后执行；生成报告中的数值及坐标按 12 位小数输出（原始完整 DXF 文本仍受 AutoLISP 打印精度限制）。

数据回放测试命令（需要外部案例目录，不随仓库公开用户图纸或原始报告）：

```powershell
node tests/title_geometry_replay.mjs '<案例诊断报告目录>'
```

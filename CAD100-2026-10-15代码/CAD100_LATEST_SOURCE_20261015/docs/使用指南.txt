出图100% 使用指南
版本：v1.9.15

一、运行条件

1. 本软件为便携版，无需安装，解压后双击“出图100%.exe”运行。
2. 电脑必须安装 AutoCAD 2020 或更高版本。
3. 软件会自动查找 accoreconsole.exe，并优先使用电脑中已安装的最高版本。
4. 原始 DWG 不会被覆盖，处理结果会写入新建的输出文件夹。

二、推荐操作顺序

1. 选择文件夹
   选择需要处理的 DWG 所在目录。当前版本读取所选目录第一层中的 DWG，不递归读取子文件夹。

2. 扫描图纸
   点击“扫描图纸”，等待程序读取图框、图签、图名、图号和其他字段。
   扫描完成后，在图纸列表中逐项查看处理状态和问题提示。

3. 核对和填写信息
   可直接在图纸列表和本批次统一信息区域修改图名、图号、设计项目号、项目名称、日期、图别、比例、单位等内容。
   显示“待人工核对”或“未确认”的图纸，应先核对并补齐信息，再点击确认。
   不需要处理的图纸，应在处理前取消选择或标记跳过。

4. 填写人员姓名及签字
   人员栏包括：设计总负责人 3 位、专业负责人 3 位、设计、校对、审核、审定。
   姓名可直接填写；签字可选择对应的签字 DWG。留空表示保留图纸原值，点击清空表示明确删除。

5. 开始处理
   确认信息后点击“开始处理”。单张图纸失败时，程序会记录失败项并继续处理其他图纸，不会因此终止整个批次。

6. 打开输出文件夹
   处理完成后点击“打开输出文件夹”查看成果。
   如果同名输出目录已存在，软件会自动创建 V1.0、V2.0、V3.0……，避免覆盖上一次结果。

三、状态说明

1. 可处理：已识别到可替换的图框和必要信息。
2. 待人工核对：存在图名、图号或其他字段缺失、冲突或识别不确定，需要人工确认。
3. 处理失败：该张图没有通过处理或最终验收，需要手动处理；其他成功图纸仍会正常输出。
4. 未确认：人工编辑的信息尚未确认，不建议直接开始处理。

四、图框处理说明

1. 支持模型空间和布局空间中的图框。
2. 支持常规块、XREF 图框以及可明确识别边界的布局炸开图框。
3. A0、A1、A2及其加长规格会按照实际宽高匹配，避免用普通图框替换加长图框。
4. XREF、天正代理对象或极不规范的图纸仍可能识别失败。失败项会在问题清单和处理报告中记录，需人工检查。
5. 不要把“处理成功”等同于图纸完全正确，应查看最终验收结果，并抽查重要图纸。

五、AutoCAD Core 自动检测

1. 软件会扫描 AutoCAD 标准安装目录和 Windows 注册表。
2. 当前支持 AutoCAD 2020–2027，并优先使用已检测到的最高版本。
3. 该逻辑不是按每张 DWG 的保存版本逐张切换 Core，而是为本次运行选择一套可用的最高版本 Core。
4. 如果未检测到 Core、路径失效或版本低于 2020，程序会阻止处理并提示重新选择 accoreconsole.exe。
5. 推荐使用 AutoCAD 2021 或更高版本；对天正及代理对象的文字读取通常更可靠。

六、问题反馈

遇到异常时，请导出“问题清单”或“处理记录”，并将以下资料一并发送给维护人员：

1. 问题清单或处理报告；
2. 出问题的源 CAD 文件名称；
3. 预期内容与实际结果的简短说明；
4. 如方便，可附异常位置截图。

请优先发送报告，不要只发送文件夹路径。报告中包含失败阶段和错误信息，更便于定位问题。
